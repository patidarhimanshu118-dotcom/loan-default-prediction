# loan-default-prediction
Machine learning project for predicting loan default risk using financial and credit-related attributes.
Loan Default Prediction is a machine learning project developed to predict whether a borrower is likely to default on a loan based on financial and credit-related attributes. The primary objective of this project is to assist financial institutions in assessing credit risk and making informed lending decisions through data-driven insights.

The project involves comprehensive data preprocessing, including handling missing values, cleaning inconsistent records, and encoding categorical variables to prepare the dataset for machine learning algorithms. Exploratory data analysis was performed to understand the relationships between various borrower characteristics and loan default behavior.

Multiple classification models, including Gaussian Naive Bayes and Random Forest, were implemented and evaluated to identify patterns associated with loan default risk. Model performance was measured using metrics such as accuracy, precision, recall, F1-score, and confusion matrix analysis. The final model achieved 76.4% test accuracy and a 78.1% F1-score, demonstrating its effectiveness in classifying borrowers based on their likelihood of default.

Key insights from the project revealed that factors such as credit history, income level, and loan amount play a significant role in determining loan repayment behavior. This project provided practical experience in data preprocessing, feature engineering, machine learning model development, model evaluation, and predictive analytics.

Technologies used include Python, Pandas, NumPy, Matplotlib, Seaborn, and machine learning techniques for classification and risk prediction.
